# Privacy policy

PR Stack Grouping for GitHub does not collect, transmit, or share any personal data.

- It runs only on `github.com`.
- It reads the pull request list you are viewing and requests PR hovercards from github.com using your existing browser session, to find each PR's base and head branch.
- It stores two things locally in your browser: the on/off setting (`chrome.storage.sync`) and a cache of branch names per PR (`chrome.storage.local`, kept for up to 30 days).
- It sends nothing to the author or any third party, and has no analytics or remote code.

Questions: open an issue at https://github.com/FIITAY/github-pr-stack-extension/issues.
